# PokéLink

PokéLink is a Pokémon-themed networking website for trainers and students. It brings career growth and community together, letting visitors explore trainer profiles, connect with peers, and discover Gym Leaders and challenges.

## Pages

- **Home:** Highlights the trainer network and community feed.
- **Profile:** Presents a trainer profile and skills.
- **Network:** Browse student profiles and connect with other trainers.
- **Gyms:** Explore Gym Leaders and challenge information.
- **About:** Learn about the PokéLink trainer community.

## Built With

HTML, CSS, and JavaScript.
